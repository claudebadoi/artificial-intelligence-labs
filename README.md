# Artificial Intelligence Labs

A collection of hands-on laboratory projects developed for the **Artificial Intelligence Systems (SIA)** university course.

This repository documents my progress in learning MATLAB, implementing artificial intelligence algorithms, and applying mathematical and computational concepts through practical exercises.

## Objectives

- Develop programming and problem-solving skills using MATLAB.
- Understand fundamental artificial intelligence concepts and algorithms.
- Implement and test mathematical and machine learning techniques.
- Visualize and analyze experimental results.
- Maintain structured, reproducible, and well-documented laboratory projects.

## Repository Structure

Each laboratory is organized into its own directory, containing source code, documentation, and experimental results.

- `examples/` – Implementations of laboratory examples.
- `exercises/` – Solutions to practical exercises.
- `results/` – Generated figures, visualizations, and screenshots.
- `README.md` – Laboratory-specific documentation and explanations.

## Getting Started

**Requirements:**

- MATLAB installed on your computer.
- Git (optional, for version control).

**Running MATLAB scripts:**

1. Clone or download the repository.
2. Open MATLAB.
3. Set the Current Folder to the desired laboratory directory.
4. Open a `.m` file.
5. Execute the script using the **Run** button or `F5`.
6. Review the results in the Command Window and generated figures.

Some exercises may require additional MATLAB toolboxes. Any such requirements will be documented in the corresponding laboratory README.
